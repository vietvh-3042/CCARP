-->.</span>Confirming a suspected hallucination</h2><p class="mt-4 leading-relaxed text-foreground">A hallucination is output that is factually wrong or inconsistent with the context the model was given. It is dangerous because it rarely looks wrong. Claude can display quotes that may look authoritative or sound convincing, but are not grounded in fact. Fluency tells you nothing, so a suspicion has to be confirmed with a check that does not depend on how the answer reads.</p><p class="mt-4 leading-relaxed text-foreground">Three checks confirm a hallucination in a running system.</p><ol class="mt-4 leading-relaxed text-foreground list-decimal space-y-1 pl-6"><li class="pl-1"><strong class="font-semibold">Check claims against the sources.</strong> Ask Claude to extract word-for-word quotes from the documents before it does its task. A claim with no quote behind it is suspect.</li><li class="pl-1"><strong class="font-semibold">Check consistency across samples.</strong> Run the same prompt several times and compare the outputs. Facts that change from run to run were probably generated, not retrieved.</li><li class="pl-1"><strong class="font-semibold">Verify citations.</strong> After Claude generates a response, have it find a supporting quote for each claim, and retract any claim it cannot support. Three causes are common:</p><ul class="mt-4 leading-relaxed text-foreground list-disc space-y-1 pl-6"><li class="pl-1"><strong class="font-semibold">Missing grounding.</strong> The answer is not tied to the text.
