The model reads it and usually follows it, but it decides each time. A hook is not up to the model. Use a hook when a rule must hold every single time: formatting after every edit, a lint before a turn can end, or a destructive command that must never run.</p><p class="mt-4 leading-relaxed text-foreground">A hook has three parts. The <strong class="font-semibold">handler</strong> is the command that runs.
