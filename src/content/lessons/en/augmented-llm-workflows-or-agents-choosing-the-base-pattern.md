id="section-3" class="scroll-mt-20 text-xl font-semibold leading-snug text-foreground" data-lesson-section=""><span class="mr-2 tabular-nums font-normal text-muted-foreground">3<!-- -->.</span>Start simple and add complexity only when it pays</h2><p class="mt-4 leading-relaxed text-foreground">The default is the simplest design that works, and that is often not an agentic system at all. For many applications, a single LLM call improved with retrieval and in-context examples is enough. Current Claude models handle most multistep reasoning inside one call, so a pipeline you build to imitate that reasoning may add nothing.</p><p class="mt-4 leading-relaxed text-foreground">Every layer you add costs something. Agentic systems usually trade latency and cost for better task performance, so the real question is whether that gain is worth paying for in this application. Each extra call adds a round trip and more tokens, and each handoff is another place the system can fail. Add a workflow when a single call measurably falls short. Add an agent only when you also need the flexibility of model-driven decisions.</p><p class="mt-4 leading-relaxed text-foreground">Frameworks deserve the same caution. Tools such as the Claude Agent SDK make it easy to start by handling model calls, tool parsing and chaining. They can also hide the underlying prompts and responses, which makes debugging harder, and they make it tempting to add complexity a simpler setup would not need. Many patterns take only a few lines of code against the API directly. several LLM calls at the same time and combines their outputs in code. It has two forms. Learn to tell them apart by asking whether the calls do different work or the same work. <strong class="font-semibold">Sectioning</strong> splits a task into independent subtasks that run in parallel: one call checks generated code for vulnerabilities while another checks the same code for licensing problems, and code merges both into one report. <strong class="font-semibold">Voting</strong> runs the same task several times to get different outputs, for example several prompts reviewing code for vulnerabilities, with the code flagged if any of them finds a problem.</p><p class="mt-4 leading-relaxed text-foreground">Sectioning often helps quality as well as speed.
