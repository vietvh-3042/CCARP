earlier conversation history to free room in the context window; the mechanics are in <a class="text-primary underline underline-offset-2 hover:no-underline" Compaction can fail in a loop. If the context fills back to the limit straight after compacting, three times in a row, Claude Code stops with an "Autocompact is thrashing" error instead of burning more API calls. That error tells you something specific: whatever keeps refilling the window is still in the conversation, so compacting or retrying again won't help.</p><p class="mt-4 leading-relaxed text-foreground">The fix is to stop the refill at its source. A typical case is reading a 40,000-line log in one go.
