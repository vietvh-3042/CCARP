Some spend months on elaborate architectures, only to find that better prompting of one agent got the same results.</p><p class="mt-4 leading-relaxed text-foreground">Splitting has a price. In Anthropic's testing, multi-agent implementations typically used <strong class="font-semibold">3-10x more tokens</strong> than a single agent on the same task. id="section-2" class="scroll-mt-20 text-xl font-semibold leading-snug text-foreground" data-lesson-section=""><span class="mr-2 tabular-nums font-normal text-muted-foreground">2<!-- -->.</span>The coordinator pattern and isolated subagent context</h2><p class="mt-4 leading-relaxed text-foreground">In the coordinator pattern, one lead agent plans the work, sends each piece to a subagent, and puts the results together. What makes this useful is isolation. Each subagent starts with a fresh conversation, its intermediate tool calls and results stay inside it, and only its final message goes back to the parent. A research subagent can read dozens of files without any of that content building up in the main conversation. The parent receives a short summary, not every file the subagent read.</p><p class="mt-4 leading-relaxed text-foreground">A support agent shows why this matters. If every order lookup puts thousands of tokens of order history into context, the agent reasons worse about the customer's technical problem. Move the lookup into its own agent, and the main agent gets back 50-100 tokens of order status and date while its context stays focused. Isolation works best when the subtask produces a lot of material that the main task mostly doesn't need, and when there are clear criteria for what to extract.</p><p class="mt-4 leading-relaxed text-foreground">Isolation applies to the conversation, not to the environment. In Managed Agents, all agents in a session share the same sandbox, filesystem and vault credentials. Each one runs in its own session thread, an event stream with its own conversation history. A Managed Agents subagent's thread also stays available, so the coordinator can send it follow-up questions and the subagent remembers its earlier turns.</p><p class="mt-4 leading-relaxed text-foreground">A subagent is the right tool for one side task whose working material you want kept out of the main conversation.
