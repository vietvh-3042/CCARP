-->.</span>What a monolithic tool set costs before any work starts</h2><p class="mt-4 leading-relaxed text-foreground">A monolithic context strategy puts every tool definition into the context window on every request. That is the baseline that progressive discovery is measured against. Tool definitions count toward the context window just as messages do. The full cost of carrying too many tools is covered in <a class="text-primary underline underline-offset-2 hover:no-underline" href="/en/lessons/capability-bloat-why-too-many-tools-degrade-an-agent/">Capability bloat: what too many tools cost</a>. The angle here is how large that fixed cost gets. A typical multiserver setup that connects GitHub, Slack, Sentry, Grafana and Splunk can use about 55k tokens on definitions before Claude does anything useful. The Agent SDK documentation gives a smaller rule of thumb: 50 tools can take 10–20K tokens.</p><p class="mt-4 leading-relaxed text-foreground">Tokens are only half of the cost. Claude's ability to pick the right tool degrades once more than 30–50 tools are available at the same time. An agent that worked well with two MCP servers can start choosing the wrong tool after a third or fourth server is connected, even though no single tool changed. Context rot adds to this. As the token count grows, accuracy and recall both decline, so a large block of mostly unused definitions also makes everything else in the window harder to use.</p><aside class="my-6 rounded-lg border-l-4 border-l-primary border-y border-r border-border bg-primary/5 p-4"><p class="mb-1.5 flex items-center gap-1.5 text-xs font-semibold uppercase tracking-wide text-primary"><svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="lucide lucide-target h-3.5 w-3.5 shrink-0" aria-hidden="true"><circle cx="12" cy="12" r="10"></circle><circle cx="12" cy="12" r="6"></circle><circle cx="12" cy="12" r="2"></circle></svg>On the exam</p><p class="text-sm leading-relaxed text-foreground">The number to remember for tool-selection accuracy is 30–50 tools loaded at once.
